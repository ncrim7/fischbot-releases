# FischBot — downloads

Free auto fishing for Roblox *Fisch*. It casts, waits for the bite, answers the shake, and reels
the fish in — by watching your screen, not by clicking on a timer.

**[Download the latest release](../../releases/latest)** · **[Website, setup guide and FAQ](https://fischbot.cirim12.workers.dev)**

This repository holds the builds only. Every release lists the file's SHA-256 and links a
VirusTotal report, so you can check that the file you downloaded is the file that was scanned.

## What you need

- Windows 10 or 11, 64-bit
- Roblox in windowed or borderless mode — not exclusive fullscreen, where nothing can read the screen

Nothing else. The download is one program; there is no installer, no key system, no account, and
no runtime to install first.

## What it does to your machine

It reads a small rectangle of your screen, moves the mouse, and presses one navigation key. It
never reads or writes Roblox's memory or files, and it never sends anything anywhere. Your
settings live in `%AppData%\FischBot\profile.json`.

## Worth knowing before you run it

Roblox's rules prohibit automation. Using this can cost you your account, and nobody can promise
otherwise. Don't run it on an account you would hate to lose.
